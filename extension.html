TRANSPARENCY & SECURITY

Required Permissions & Why

We adhere strictly to the principle of least privilege. NuvoraTab only asks for what is necessary to run your new tab.

Permission Purpose Privacy Status
storage Stores your personal wallpaper preferences, rotation settings, and overlay darkness locally on your device. ✓ 100% Local Storage Only
chrome_url_overrides.newtab Allows NuvoraTab to replace the default blank browser tab with the curated HD wallpaper dashboard. ✓ Zero History Access
None Requested No permissions requested for bookmarks, browsing history, cookies, web requests, or microphone/camera. ✓ Strictly Prohibited
SETUP IN 30 SECONDS

How to Install NuvoraTab

Get started in three simple steps. Fully compatible with Google Chrome, Brave, and Microsoft Edge.

1

Click Add to Chrome

Visit the official Chrome Web Store listing and click the Add to Chrome button to download the extension.

2

Open a New Tab

Press Ctrl + T (or Cmd + T on macOS). Confirm "Keep Changes" when prompted by your browser.

3

Enjoy Fresh HD Views

Instantly enjoy high-definition wallpapers every time you start browsing. Customize categories anytime.
